# コマンド置き換えルール（commands.md）

このファイルはユーザーのローカル環境の alias を、Claude がコマンド提案時に踏まえるためのルールを定義する。

---

## 置き換え対象

ユーザーのシェルでは以下の alias が設定されている。コマンド例を提示する際は alias 後の名前を使う：

| 標準コマンド | 提示で使う名前 |
|---|---|
| `grep` | `rg`（ripgrep） |
| `ls`   | `eza -a` |
| `cat`  | `bat` |
| `less` | `bat` |

Why: 標準コマンド名で提示すると、ユーザーが手元で実行する際に alias と挙動・オプションが食い違い、コピペが動かない、または別の結果になるため。
